# COMP1888 Lab 7: Pandas Sorting, Subsetting & Data Manipulation

Exercises and walkthroughs for **COMP1888 Lab 7**, covering sorting, positional and label-based indexing, conditional filtering, derived columns, and data manipulation in Python with **pandas**.

## Contents

- `ex7_Data_Manipulation_Part_I_Sorting.ipynb` — Executed Jupyter notebook covering the `brics` DataFrame walkthrough and `uk-500.csv` exercises (`Q1`–`Q10`) across sorting, `.iloc`/`.loc` selection, boolean and string filtering, index slicing, and derived columns (`Fullname`).
- `lab7_all_tasks.py` — Standalone Python script for loading, filtering, creating derived columns, and verifying the lab tasks.

## Setup & Usage

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install pandas jupyterlab notebook
jupyter lab ex7_Data_Manipulation_Part_I_Sorting.ipynb
```
